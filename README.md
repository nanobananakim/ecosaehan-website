# 에코새한 홈페이지

조달청 등록 야자매트(보행매트) 전문 제조기업 에코새한의 Next.js 원페이지 홈페이지입니다.

## 로컬 실행

Node.js 20 이상을 설치한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## Vercel 배포

GitHub 저장소에 push한 뒤 Vercel에서 저장소를 Import하면 별도 설정 없이 배포할 수 있습니다. 프레임워크는 Next.js로 자동 인식됩니다.

카탈로그 PDF나 자재승인원은 추후 `public/` 폴더에 추가하고, 제품 섹션의 자료실 링크를 연결하면 됩니다.
